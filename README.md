# OrBit Client downloads

Official installers for the native OrBit Launcher. Client features are included, and the launcher automatically downloads and manages its Cinnabar runtime.

| Platform | Installer |
| --- | --- |
| Windows, 64-bit | [Download .exe](https://github.com/tbn201/OrBitClient-Releases/releases/latest/download/OrBit-Launcher-windows-x64-setup.exe) |
| macOS, Apple Silicon | [Download .dmg](https://github.com/tbn201/OrBitClient-Releases/releases/latest/download/OrBit-Launcher-macos-apple-silicon.dmg) |
| macOS, Intel | [Download .dmg](https://github.com/tbn201/OrBitClient-Releases/releases/latest/download/OrBit-Launcher-macos-intel.dmg) |

[Release notes and checksums](https://github.com/tbn201/OrBitClient-Releases/releases/latest)

Run the Windows installer, or open the macOS disk image and drag OrBit Launcher into Applications. Open the launcher and select Install & Launch.

OrBit client source is private. The [OrBit Cinnabar fork](https://github.com/tbn201/cinnabar-orbit) and its runtime releases remain public. This repository contains downloads and release information.
